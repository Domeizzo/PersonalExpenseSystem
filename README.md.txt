# Sistema di Gestione Spese Personali
Questo software permette di monitorare le uscite finanziarie, categorizzarle e impostare budget mensili.

## Struttura del Progetto
- `src/`: Contiene il codice sorgente Python (`main.py`).
- `sql/`: Contiene il database (`spese.db`) e lo schema di creazione (`schema_database.sql`).
- `doc/`: Relazion finale in PDF.

## Requisiti
- Python 3.x
- SQLite3 (incluso in Python)

## Come avviare il programmma
1. Apri il terminale (CMD).
2. Entra nella cartella `src`.
3. Digita: `python main.py`
